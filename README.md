# Welcome2NeWorld

Este repositorio contiene una página web diseñada para funcionar como punto de acceso tras escanear una etiqueta NFC.

## 📱 Características

- Redirige automáticamente a esta web desde una etiqueta NFC
- Detecta si el usuario está usando un dispositivo Android o iOS
- Muestra solo los botones de descarga relevantes para el sistema operativo
- Incluye un código QR siempre visible para conectarse automáticamente a la red WiFi
- Oculta los botones si se accede desde un ordenador, mostrando un mensaje informativo

## 🧩 Archivos incluidos

- `index.html`: archivo principal de la web con lógica de detección por sistema operativo
- `wifi_qr.png`: imagen del código QR para conexión WiFi (**debes añadirla tú manualmente**)

## 🚀 Cómo usar

1. Sube los archivos a tu repositorio público de GitHub
2. Activa GitHub Pages desde la configuración
3. Apunta tu etiqueta NFC a la URL generada (por ejemplo: `https://decoi89.github.io/Welcome2NeWorld/`)
